# PRE

This repository contains code for the PRE experiments.

- `PRE_fineweb/`: next-token prediction experiments and recurrent transformer variants.
- `PRE_RL/`: reinforcement-learning experiments for Sokoban and Craftax.

To run the PRE code, enter the relevant subfolder and follow its README.

## Rebuttal figures and tables

The compiled [rebuttal figures and tables PDF](rebuttal/rebuttal_figures_and_tables.pdf)
collects the additional plots, statistical comparisons, seed-level results,
and hardware measurements cited in the rebuttal.
