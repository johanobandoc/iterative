# Comment 1/3: Significance tests and conclusions

Each seed contributes one score: the mean of its final five logged episodic returns. For each benchmark, budget, and exact depth, we select the configuration with the highest mean score. We compare the selected configurations using one-sided Welch $t$-tests:

$$H_0: \mathbb{E}[Q_{L_a}] \leq \mathbb{E}[Q_{L_b}] \qquad\text{vs}\qquad H_1: \mathbb{E}[Q_{L_a}] > \mathbb{E}[Q_{L_b}].$$

Runs are treated as independent. The tests are exploratory and reported without multiple-comparison correction. Positive $\Delta Q$ favors the higher-depth configuration named first. Small- and medium-budget comparisons use nine seeds per configuration; large-budget comparisons use three.

For Craftax, neither the $L=4$ versus $L=2$ test nor the $L=2$ versus $L=1$ test is significant at any budget.
